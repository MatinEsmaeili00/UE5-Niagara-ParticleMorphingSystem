# 🌌 Particle Morphing System – Real-time Shape Transitions with Niagara

A creative Niagara-based system that **morphs thousands of particles between 3D models or images in real time**, allowing artists and developers to design stunning transitions and dynamic visual effects effortlessly.

Built in Unreal Engine 5 using **Niagara, Material, and Blueprint logic**.


---

## ✨ Features

- 🧊 **Starting and target shapes** (from mesh or image)
- ⏱️ **Transition speed**
- 🎮 **Interactive triggers** (timed or event-driven)
- 🎨 **Color, fade, and movement styles**
